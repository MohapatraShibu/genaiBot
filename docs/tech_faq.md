# Tech FAQ

## What is Python?
Python is a high-level, interpreted programming language known for its simplicity and readability. It supports multiple programming paradigms including procedural, object-oriented, and functional programming.

## What is an API?
An API (Application Programming Interface) is a set of rules that allows different software applications to communicate with each other. REST APIs use HTTP methods like GET, POST, PUT, DELETE to interact with resources.

## What is Docker?
Docker is a platform for developing, shipping, and running applications in containers. Containers package code and dependencies together, ensuring consistent behavior across environments.

## What is a database index?
A database index is a data structure that improves the speed of data retrieval. It works like a book index — instead of scanning every row, the database jumps directly to the relevant data. Indexes trade storage space for query speed.

## What is Git?
Git is a distributed version control system that tracks changes in source code. Key commands: `git clone`, `git commit`, `git push`, `git pull`, `git branch`, `git merge`.

## What is CI/CD?
CI/CD stands for Continuous Integration and Continuous Deployment. CI automates testing when code is pushed. CD automates deployment to production after tests pass.
